# 演出策划招募

## 我们的项目 ： **Knot Editor 结绳编辑器**

我们正在开发一个基于 Unity 的剧情演出编辑器，目标是为演出策划提供一个可视化的剧情编写工具，帮助他们直观地复用各个组件达到丰富的演出效果。

这个项目的**特点**是以下几个方面：

### 可视化编辑界面

我们将设计一个直观的可视化编辑界面，允许演出策划通过**拖拽**不同的组件到场景中，来实现不同的演出效果。同时，他们也可以通过配置组件的参数，来调整不同的演出效果。

### 组件库

我们将提供一个丰富的组件库，包含不同的演出元素与功能，如**富文本、运镜、分镜、人物动作、表情、音乐、光线变化、特效**等。这些组件将被设计为可复用的模块，演出策划可以根据需要进行组合与配置。
不同的组件会在 2D 和 3D 场景中被单独设计，但不同的组件并不会影响编辑器的架构，所以 Knot 编辑器是一款通用场景的编辑器，在 2D 和 3D 场景中都能有良好的表现。

Knot 编辑器将由本团队进行初步开发，并且开发完成后会开源，作为 Unity 的一个插件使用。同时，我们重视社区力量，在后续会开放 Github 社区开发，欢迎来自社区的开发者加入。

# 演出策划的工作

###### **前期：拆解不同游戏的演出元素**

在各个游戏中找到不同的演出元素，如富文本、运镜、分镜、人物动作、表情、音乐、光线变化、特效等，将其**归类整理**。

###### **前期：探究相关功能的现有参考**

在 Unity 中，有许多相关的功能可以实现不同的演出效果，如 _TextMeshPro_ 插件提供了富文本的功能，而 _Cinemachine_ 插件则可以实现运镜的切换。

同时，我们注意到社区中也有如 _Fungus_ 这类与我们功能相似的项目，我们也需要学习并借鉴他们的功能与逻辑。

###### 中期：设计不同的演出功能

根据不同的演出元素，设计出不同的演出功能，如对话文本的富文本表现、运镜的表现、分镜的切换、人物动作的播放与暂停、表情的变化、音乐的播放与暂停、光线变化的实现等。

这些功能需要被尽量地整理与归纳，相同的功能集成在一个功能扩展当中，最终形成一个完善的演出功能库。

###### 后期：体验我们的设计与交互模式

在每个扩展开发完成后，我们会邀请演出策划来测试与体验这个功能。而在项目完成后，策划也会受邀体验编辑、调式、配置等基本功能，并且给予反馈。

在正式发布版本之前，我们会确保缩减用户可能遇到的各种问题，包括此产品的使用方式是否能被广泛接受。
