# 帧行为

## 帧运行

帧将内部的多个指令封装起来，帧内指令与相邻帧内指令独立，互不干扰。

### 指令协调

指令协调是指挥帧内指令如何相互配合执行的重要方式。

在帧内，协调指令的触发执行方式有两种：

1. **时间触发**：使用**时间延迟**的方式决定指令在何时触发执行；
2. **事件调用**：在帧内使用**事件触发**调用一个或多个指令；

二者会相互配合，共同构成协调的逻辑。

### 协调参数

#### Frame 内

`OnFrameStart`:在进入帧时响应。

#### Instruction 内

- `Events[]`：在指令内定义各种待响应的事件；

  - `OnInstructionStart`：在指令被调用时响应；
  - `OnInstructionEnd`：在指令运行结束时响应；
  - `Customed Event`：定义各种在指令运行过程中可能触发的某种事件；
- `PreDelay`：被事件调用时，等待一段时间后才真正进入运行；
- `InvokeEvent`：指定一个调用自己的事件，在触发时被调用。

## 帧推进

本帧所有指令运行完成后，停止，玩家通过**输入操作**进入下一帧；或接管推进权限，禁止玩家手动中断和推进。

### 输入参数

`Event Push Forward`：输入事件触发；

`is Can Push`：是否能够手动推进；

`is Auto Push`：是否在帧结束时自动推进；

## 帧中断（跳过）

玩家通过输入操作<u>跳过本帧</u>。但在跳过本帧时，帧内所有指令会立即执行到结束状态。

### 输入参数

`Event Interrupt`：输入事件触发；

`is Can Insterrupt`：是否能够手动中断；

## 暂停

点击暂停，停止当前帧所有正在运行的指令；解除暂停后，当前帧所有指令恢复运行，中间不中断或重置。

### 输入参数

`Event Pause`：输入事件触发；

`Action Pause`：暂停指令；

`is Can Pause`：是否能够暂停；
